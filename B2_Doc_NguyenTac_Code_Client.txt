## 5. PHÂN LOẠI KẾT QUẢ

Mỗi phát hiện phải được phân loại:

- CONSISTENT: Đang đồng nhất và hoạt động tốt.
- INCONSISTENT: Đang thiếu đồng nhất.
- OUTDATED: Có dấu hiệu thiết kế lỗi thời.
- DUPLICATED: Có component hoặc CSS bị trùng lặp.
- CONFLICT: Có sự xung đột giữa tài liệu và source code.
- MISSING: Chưa có quy chuẩn hoặc component cần thiết.

Đưa ra bằng chứng cụ thể bằng đường dẫn file, tên component, CSS variable hoặc đoạn code liên quan.
